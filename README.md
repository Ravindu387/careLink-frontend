# CareLink – Frontend

**An AI-Powered Flood Disaster Relief and Humanitarian Crisis Management System**

CareLink is a web-based disaster management platform designed to support communities affected by floods and other emergencies. It aims to connect affected people, volunteers, relief organizations, and authorities through a centralized digital platform.

This repository contains the frontend application of the CareLink system.

## 🚀 Technologies Used

- React
- TypeScript
- Vite
- HTML5
- CSS3
- JavaScript / TSX
- Git & GitHub

## ✨ Key Features

- **Home Page** – Introduction to the CareLink platform.
- **Emergency Assistance** – Interface for requesting emergency support.
- **Shelter Information** – Access to information about available shelters.
- **Disaster Updates** – Display important disaster-related announcements.
- **Volunteer Support** – Information and access for people interested in volunteering.
- **Responsive Design** – User-friendly interface for desktop, tablet, and mobile devices.

*Note: Features will be implemented progressively during development.*

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/careLink-frontend.git
```

### 2. Navigate to the Project Directory

```bash
cd careLink-frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### 5. Build for Production

```bash
npm run build
```
